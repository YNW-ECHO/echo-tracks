🔒 100% offline — why does install mention permissions?
Android shows a standard warning because Echo Tracks asks for READ_SMS (to auto-read M-PESA/bank SMS) + POST_NOTIFICATIONS (bill + update alerts) + INTERNET (only to check GitHub Releases for updates).

Your data never leaves the phone: SMS are parsed on-device, stored in a local Room database, PIN in encrypted prefs. No account, no analytics, no server, no ads. You can even turn off internet after install — tracking keeps working, only the update check pauses.
Source: SmsReader.kt → EchoDb (local) — nothing is uploaded anywhere.
